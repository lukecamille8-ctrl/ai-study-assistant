# AI Study Assistant — StudyMate portfolio

A polished, responsive landing page for the AI Study Assistant project. The site introduces the product concept, highlights its student-first study workflow, and links visitors to the repository.

## Preview locally

Open `index.html` in a browser. The page is self-contained and does not require a build step, dependencies, or external assets.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. After the deployment finishes, open the Pages URL shown in Settings.

## Customize

Edit the copy, colors, and sections in `index.html`. The page uses inline CSS and standard HTML, so it can also be hosted on any static site provider.
